## Compatibility and migration

這是第一個 public schema，沒有舊版 migration。Importer 僅接受
`schemaVersion=1.0.0` 與 `modelVersion=bottom-up-1.0.0`；不支援版本會以 typed
error 拒絕，既有 browser data 不會被覆寫。未來修改公式、parameter semantics
或 snapshot contract 時，必須 bump version 並另寫 migration／release note。

## Privacy and security boundary

案件內容只存在 browser `localStorage` 或目前 session；沒有 database、Analytics、
AI、接收案件內容的 API 或 Server Action。請勿輸入或匯入公司機密、個人資料、
真實乙方名稱、NDA 內容或未公開報價。

## Known limitations and rollback

- Public parameter set 為 fictional／illustrative，不是市場標準或正式報價。
- 沒有帳號、跨裝置同步、server-side audit log 或公司 rate card。
- GitHub remote 的 repository casing、Git integration、branch ruleset 與
  Private Vulnerability Reporting 需由 repository owner 完成 remote governance。
- 發生 regression 時，先在 Vercel promote 前一個已驗證 deployment，再 revert
  對應 commit；若涉及 model／schema，必須同時保留 version 與 migration 說明。
