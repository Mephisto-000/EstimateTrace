## Formula typography

- KaTeX stylesheet 改由 root layout 載入為 hashed same-origin asset，讓 direct
  load 與 App Router client navigation 都使用一致的數學字型。
- Methodology display formula 改為 responsive `32–44px`；Calculation trace
  改為 `21.6–26.4px`。
- 公式現在使用 `KaTeX_Main`／`KaTeX_Math italic`、真正上下標、fraction
  layout 與 display-size sum／product operator，不再呈現為
  monospace-like linear text。
- 過長公式保留 formula-level keyboard focus 與水平捲動；`640px`、`360px`
  viewport 均不造成 document overflow。

## Compatibility and security

- Domain formula、stable snapshot text、result、schema、model 與 parameter
  set 都未改變；browser estimate data 不需要 migration。
- Formula expression 仍只來自 source-controlled domain registry；KaTeX 維持
  `trust=false`、bounded expansion／size 與 escaped-text fallback。
- CSS 與 fonts 皆由 Vercel same-origin static assets 提供，不使用 CDN、
  remote font、analytics 或 third-party tracker。
