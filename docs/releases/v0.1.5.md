## Vercel Hobby 流量強化

- 移除唯一的動態 `/estimates/[id]` route，改以 `afterFiles` rewrite 將可見案件
  URL 對應到固定的 `/estimates/editor` 靜態殼層。
- 編輯器頁宣告 `dynamic = "error"`；production build 的所有 application route
  都是 static output。Vercel editor prerender config 為
  `isDynamicRoute=false`、`expiration=false`，正常案件請求使用 file fallback，
  不執行 application Function。
- 關閉 site header、footer、次要 CTA、案件清單與 wizard 內的非必要
  background prefetch；首頁只保留主要「開始估算」行動的預抓取。
- Wizard 步驟以 History API 更新 `step` query 與 client 畫面，切換步驟不再
  發送 RSC request。
- 案件路徑驗證與 storage schema 共用 RFC UUID 規則，支援 schema 已接受的
  UUID v1–v8。

## 相容性、安全性與隱私

- 可見 URL 維持 `/estimates/<opaque UUID>?step=...`；直接載入、重新整理、
  Link 導覽與另開分頁行為不變。
- 案件名稱、描述、工作項目、金額與 JSON 內容仍只在瀏覽器處理；未新增
  Route Handler、Server Action、Middleware、analytics 或 third-party tracker。
- 未新增、升級或移除 dependency。
- 未變更估算公式、數值參數、stable snapshot text、schema、model 或計算結果；
  既有案件不需要 migration。
